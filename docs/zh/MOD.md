# Mod 指南

> [← 返回 README](README.md)

## 安装

1. 从 [Releases](https://github.com/576576/mdtC/releases) 下载 `mdtc-[version]-Desktop.jar`
2. 在 Mindustry 中进入 **Mods** → **导入 Mod** → 选择 JAR 文件
3. Mod 自动加载，无需重启

## 使用

1. 打开任意 **Micro Processor** 或 **Logic Processor** 方块
2. 在处理器代码对话框中，底部工具栏出现 **MdtC** 按钮
3. 点击打开 MdtC 双栏编辑器

### 编辑器布局

```
┌──────────────────────────────────────────┐
│  [编译] [反编译] [格式化]          [设置]  │
├───────────────────┬──────────────────────┤
│  源码 .mdtc        │  输出 .mdtcode       │
│  [导入/复制/清空]   │  [导入/复制/清空]    │
│  (可编辑)          │  (可编辑)            │
├───────────────────┴──────────────────────┤
│  状态: 就绪                              │
└──────────────────────────────────────────┘
```

### 工作流程

- **从处理器打开**（默认）：处理器代码自动载入右侧 → 自动反编译到左侧
- **编译**：编辑左侧 `.mdtc` → 点击编译 → 结果显示在右侧 `.mdtcode`
- **反编译**：将 `.mdtcode` 粘贴到右侧 → 点击反编译 → 结果显示在左侧
- **复制到处理器**：复制右侧内容 → 在 Mindustry 编辑器中通过 编辑 > 导入 粘贴
- **导入**：将文件内容复制到剪贴板 → 点击对应导入按钮：
  - **导入**（左栏标题旁）→ 粘贴 `.mdtc` 源码到左栏
  - **导入库**（左栏标题旁）→ 追加 `.libmdtc` 库到左栏末尾
  - **导入原生**（右栏标题旁）→ 粘贴 `.mdtcode` 原生代码到右栏

## 设置

点击 **设置** 进行配置：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 打开时自动带入 | 开 | 打开时自动导入处理器代码 |
| 自动格式化 | 开 | 反编译后自动格式化代码 |
| 缩进宽度 | 2 | 每层缩进空格数（1–8） |

设置通过 Mindustry 的设置系统跨游戏会话持久化。
