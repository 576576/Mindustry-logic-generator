# MdtC TS Language Server

TypeScript LSP implementation for MdtC, launched by the `mdtc-lsp` VSCode
extension (`node server/out/server.js --stdio`).

## Layout

- `src/server.ts` — connection, capabilities, handlers
- `src/diagnostics.ts` — runs the Java CLI jar on a temp file; adds token-exact
  bracket scan + negative-number guard scan (locale-adaptive)
- `src/data.ts` — instruction table extracted from `builtins/gen/builtins.js` (vm)
- `src/completion.ts` / `src/hover.ts` / `src/semantic.ts` / `src/goto.ts` /
  `src/formatting.ts` / `src/messages.ts` — per-feature modules

## Dev

```
npm install
npx tsc -p .            # compile to out/
npx tsc -w -p .         # watch mode (see ../README.md auto-restart loop)
```

`server/data/` is generated by `npm run prepare:data` in the extension root
(copies builtins.js, docs and the CLI jar).
